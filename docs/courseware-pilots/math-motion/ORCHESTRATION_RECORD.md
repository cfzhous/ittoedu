## 1. 输入与权威边界

- 唯一初始主题：高中数学动点问题专题课。
- 受众：高三一轮复习；学生已学一次函数、二次函数、平面几何面积与基本最值。
- 课堂：45 分钟，一人一机，教师检查点推进。
- 当前承载：固定 1280×720 的 PPT 兼容 Project V7。
- 交付优先级：HTML 互动优先；最终整课兼容 `.h5lesson`、单 HTML、网页包、PDF、PPTX。
- 内容不绑定省份、教材版本或现成试题；本课采用下列已核验模型作为数学真相。

| 模型 | 函数与定义域 | 结论 |
| --- | --- | --- |
| 母题 | `S(t) = 6t - 1.5t², 0 ≤ t ≤ 4` | `Smax = 6 @ t = 2` |
| 定义域变式 | `S(t) = 6t - 0.5t², 0 ≤ t ≤ 4` | `Smax = 16 @ t = 4` |
| 同构迁移 | `S(x) = 6x - 0.75x²` | `Smax = 12 @ (4, 3)` |

视觉概念图只规定构图、层级、色彩和互动语言，不能覆盖数学真相。核心参考图把阴影画在 `△PBQ`，但其公式使用 `AP` 与 `BQ`；实际样片必须绘制面积与公式一致的 `△APQ`，从而保证 `t = 0, 2, 4` 时面积依次为 `0, 6, 0`。

## 3. TeachingDesign 1.0（历史批准，现已失效）

### 学习目标

1. 从动点的速度、初始位置和边界条件中识别变量与约束。
2. 把几何位置关系转写为随时间变化的线段表达式，并建立面积函数。
3. 同时使用解析式、函数图象和定义域判断最值，避免只求抛物线顶点而忽略运动范围。
4. 将“约束—变量—关系—范围—解释”五步法迁移到结构相似但数值或定义域不同的问题。

### 学习证据

- 学生能在结构化候选中正确组装母题模型，并修复常见错误。
- 拖动同一变量时，能解释点的位置、线段、面积值与图象点为何同步变化。
- 面对定义域变式，能拒绝区间外顶点并改用端点比较。
- 面对同构迁移题，能独立完成有限候选中的模型识别与结论选择。

### 主要困难与纠偏

- 把速度直接当成线段长度：用时间轴与位置联动暴露量纲错误。
- 面积区域与公式不一致：让阴影面积、线段标签和计算式共享同一数值模型。
- 只看顶点、不看定义域：用定义域变式制造可恢复的错误分支。
- 会做母题但不会迁移：保持五步结构不变，只更换数值与范围。

### 教学序列

1. 预测：先锁定“最大值大概出现在哪里”。
2. 约束分类：区分常量、变量、范围与目标量。
3. 函数建模：由运动关系组装线段与面积函数。
4. 图式联动：在同一时刻联动位置、式与图象。
5. 定义域修复：处理顶点不在可行区间内的变式。
6. 同构迁移：在新图形语境中复用五步结构。
7. 方法总结：用本课证据完成五步法总结。

## 5. VisualDirection 1.0（历史方向记录）

- 视觉隐喻：一张正在推导的解析图谱，而非装饰型幻灯片。
- 背景：暖白纸面；主体线条近黑。
- 变量与运动约束：群青；目标面积与峰值：橙红。
- 字体：中文使用可靠系统黑体；数学使用系统衬线数学字体。
- 布局：同一屏同时容纳线段式、几何位置、面积区域、函数图象与时间控制；因果关系优先于装饰。
- 动效：只响应拖动和状态变化；不使用持续装饰动画。
- 避免：统一页眉、页码、大卡片壳、固定底栏、仪表盘、游戏化成功庆祝和远程字体。

## 10. 失败复盘与证据边界

1. 旧 TeachingDesign 没有完整题目包、解法、难度依据和各环节时间预算，无法证明高三一轮复习与 45 分钟容量。
2. 旧 PresentationScript 只是状态/活动表，缺少完整初始画面、操作前必须可见信息、教师动作、即时反馈、完整分支、揭示策略、时间预算和可见内容清单；它不符合当前呈现脚本合同。
3. 旧交接没有独立 `02-content-spec.md`，也没有文件路径、版本和 SHA-256；实现只能从聊天摘要和自行硬编码内容补全。
4. 实现只对齐七幕名称与状态骨架，没有脚本—场景—状态—事件—文案双向追踪，因此工程测试无法发现体验语义偏离。
5. 预测页在学生作答前没有呈现完整题面与直观化条件；约束分类和五步排序没有形成足够教学贡献。
6. 大量一次性课程内容被集中到一个 V4 组件，违反“稳定内容用原生节点、课程专属复杂行为优先运行时、真实复用才组件化”的承载原则。
7. 实现使用 Unicode `½`，浏览器按字形显示为斜线分数，违反已批准的竖式分数方向；旧测试反而固化了错误字符串。

本课例只可用于验证新 Skill 是否能阻止上述问题。新一轮必须从原始主题和空白上下文开始，先生成文件化教学设计、教学内容规格与呈现脚本，冻结首次生成结果后再评分；不得读取或延续当前失败实现。
