# 校园池塘食物网｜混合表面脚本

## Slide：提出预测

全屏照片上方保留原生标题：“蜻蜓幼虫减少，池塘里会发生什么？”下方两个原生文本分别记录“最先变化”和“可能的间接变化”。教师不展示答案，进入资料阅读。

## Flow：校准箭头含义

短讲义解释食物网箭头由食物指向取食者，包含一个三行例表和警示块：“箭头不是谁追谁，而是物质和能量流向谁。”结尾使用证据分类组件，让学生把路径短句移入“直接影响”“间接影响”或“仍需核实”；至少移动两条后记录课程状态 `pathsExplored`，再到 Spatial 中沿箭头验证。

## Spatial：追踪路径

世界坐标中放置藻类、浮游动物、蝌蚪、小鱼、蜻蜓幼虫、青蛙和鹭。主关系线与种群名称在总览可见；证据说明只在放大后出现。三个命名镜头为“全池塘”“蜻蜓幼虫邻域”“两条间接路径”，小地图始终标记当前视口。

学生从蜻蜓幼虫出发，先找直接相连节点，再沿第二条边追踪，并核对 Flow 中已选的两条路径短句。若尚未完成路径选择就进入最终说明，导航守卫提示先完成路径追踪。`pathsExplored` 只记录当前会话的路径任务进度，跨表面往返不清空。
