# 二次函数参数实验｜教学呈现脚本

## 入口：先留下分歧

画布中央呈现问题：“`a` 变大，抛物线一定变窄吗？”下方只保留三个短判断：开口方向、宽窄、是否仍为二次函数。教师邀请学生先选立场，不立即揭晓。

教师进入下一场景时说：“不要背结论，让图像连续变化。”

## 参数实验

坐标实验占主要画面，位于背景说明与上层原生提示之间。初值 `a=1`。滑杆范围为 `-3` 到 `3`，但跳过 `0`；快捷按钮提供 `-2、-0.5、0.5、2`。

运行时始终显示当前表达式 `y=ax²`、`a` 的数值以及两条短读数：开口方向与宽窄趋势。每次改变参数都更新同一条曲线，不叠加残影。第一次改变参数后记录“已实验”；比较过一正一负后记录“已比较符号”；比较过同号不同绝对值后记录“已比较宽窄”。三项完成时将课程状态 `comparisonComplete` 设为真。

运行时可见文字 `prompt` 与 `hint` 必须是稳定作者字段；坐标区中声明的可替换背景素材也必须能命中。试运行后切回编辑时保持当前参数、曲线和反馈，不把它自动保存成工程默认值。

## 总结与迁移

若未完成比较就前往总结，课件阻止导航并提示：“先各比较一组异号参数和同号不同绝对值参数。”

总结画面只出现两个待补句：

- `a` 的符号决定 ______；
- `|a|` 的大小决定 ______。

教师揭示原生公式与结论后追问：“为什么不能只说 `a` 越大越窄？”最后给出 `a=-1.6`，学生先口头预判，再返回实验验证。教师控制器始终位于最上层，运行时不能覆盖公式和控制器。
