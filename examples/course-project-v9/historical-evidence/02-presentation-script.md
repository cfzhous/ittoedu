# 工业城市证据阅读｜教学呈现脚本

## 阅读导向

开头用一级标题提出问题：“工业化让城市生活变得更好吗？”紧接一段说明：本课不要求立刻选择“是”或“否”，而要检查证据边界。

“阅读工具”折叠分节列出四问：谁写的、何时写的、看见了什么、遗漏了谁。默认展开，教师可以折叠。

## 三份材料

材料 A 为 1841—1871 年某工业城市人口与工厂数量表。表格之后的提示只问“共同变化能否直接证明因果”。

材料 B 是工厂主回忆，强调工资与机会；用引用块并给出出处。材料 C 是调查员记录，描述拥挤住房与童工；同样保留出处。每份材料后有“可支持”和“不能单独支持”两个短段落，初始内容留给学生口头补充。

## 证据归类

嵌入证据分类组件。组件收到六条短证据，目标栏为“生产与机会”“生活与代价”“仍需核实”。卡片可用鼠标或键盘移动；组件内标题、证据文字必须可点选编辑。归类结果只作为讨论草稿，不自动给分。

## 有限结论

最后呈现写作框架：“从……可以看出……；但由于……，我们仍不能断定……。”学生完成后，教师展开结论提示：评价历史变化时既要比较不同群体，也要说明证据的来源限制。
