只阅读根目录 @design.md 文档。

结合对设计的理解，按照其中的模块划分标准，生成一个单一 module 的文档，放在docs/modules 中。

文件名格式为 {subject-id}--{module-name}.md
{subject-id} 为从 001 开始递增的模块编号。

module 是面向实施设计的，并且包含本模块相关的设计原则，不需要在文档里过度规定文件及步骤。
要在开发目标的完整性、开发内容的容易踩坑、容易出现设计错误或者开发问题的部分根据业界经验进行充分考虑。

模块文档结构：

1. 模块定位
2. 基本设计原则
3. 测试边界
4. 与后续模块的接缝
5. 明确不属于本模块的设计
